# Dominion: Beyond the Stars

A mobile-first, mechanics-first grand strategy space game.

## Current playable build
- 900 procedurally generated star systems
- 32 civilizations total (player + 31 AI)
- Hyperlane network
- Surveying and exploration
- Influence-based claiming
- Orbital stations
- Habitable worlds and colonization
- Population growth
- Credits, alloys, science, influence
- Technology progression
- Fleet construction
- Autonomous AI expansion, colonization, research, and fleet growth
- Persistent local autosave after every action/turn
- Phone-first UI

## Roadmap
Warfare, ship design, diplomacy treaties, internal politics, species, leaders, traditions, deeper economy, espionage, federations, galactic institutions, events, anomalies, archaeology, subjects, crises, megaprojects, terraforming, armies, occupations, and endgame victory systems.
